Secretary Room Assignment

Use applicants already moved to Pending Exam, enter how many rooms the batch will consume, then let the system distribute them as evenly as possible. Each saved assignment keeps the batch schedule, room name, seat number, exam control number, and the applicant's official LDSP application number for printing.

Balanced random assignment per room
The room generator uses the applicants you select below. Distribution is randomized and then balanced so the rooms stay as equal as possible, for example 103 applicants across 4 rooms becomes 26, 26, 26, and 25.
If you open an existing batch and regenerate it, only records still in the scheduled stage can be replaced. Completed or encoded exam records stay protected.
